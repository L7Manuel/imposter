Instalar Impostor en Android

Para mejor experiencia y instalación completa como app, necesitas usar Chrome o Edge.

⚠️ Firefox para Android tiene soporte limitado para PWA.
Se recomienda usar Chrome/Edge para instalación completa.
1
Usa Chrome o Edge
Abre esta página en Chrome/Edge desde Play Store
2
Espera 30 segundos
Deja que la página cargue completamente
3
Instala la app
Aparecerá el botón "Instalar" o "Añadir a pantalla de inicio"
4
¡Listo para jugar offline!
La app funcionará sin conexión a internet

Nota: Firefox puede crear un acceso directo, pero no tendrá todas las funciones PWA.
